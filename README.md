# FeedbackHub

SaaS multi-tenant para restaurantes coletarem feedback de clientes via QR Code nas mesas.

## Estrutura (monorepo)

- `frontend/` — Next.js 15 + TypeScript, deploy na Vercel
- `backend/` — FastAPI + SQLAlchemy 2, deploy no Render
- Banco de dados: Supabase (PostgreSQL + Storage)

Este projeto está sendo construído passo a passo como estudo de arquitetura de SaaS moderno.
